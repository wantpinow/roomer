## Lessons from dogfooding

- The linter + wall-relative helpers make agent-driven layout reliable: the agent converged from
  first draft to a clean layout in 2–3 batches each time, guided by the hints.
- Agents need to SEE product photos next to their blockouts → comparison sheets.
- Organic/soft furniture needed richer primitives (capsule, torus, partial lathe, bevels, repeats).
- Default cameras must consider furniture (a corner camera ended up inside shelving); agents
  should add per-layout viewpoints (`set_camera`), or take photos from walk mode.
- gpt-image-2.5-sunburst preserves layout and products very well but tightens wide-angle framing;
  Gemini 3 Pro Image preserves framing exactly but sometimes shrinks furniture.
